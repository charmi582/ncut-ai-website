# 動工前備份步驟（週日進後台第一件事）

> 目的：把每個我們要動的欄位「原本的內容」先存下來，失敗時貼回去就還原。
> 原則：**先備份，再修改。** 每個欄位都備份完，才開始貼新東西。

## 步驟

### 1) 備份各欄位現有內容（最重要）
進後台，把下列每個欄位裡**目前已有的內容**，全選複製 → 貼到對應的 .txt 檔存起來：

- 首頁 → 頭部 CSS　　→ 存到 `原始_首頁頭部CSS.txt`
- 內頁 → 頭部 CSS　　→ 存到 `原始_內頁頭部CSS.txt`
- 首頁 → 頭部 HTML　 → 存到 `原始_頭部HTML.txt`
- （若有動到的自訂模組設定，也截圖或複製出來）

> 欄位若本來是空的，就在檔案裡寫「原本為空」。這樣還原時就知道「清空」即可。

### 2) 截圖存證（前台 before）
改之前，把首頁和一兩個子頁**整頁截圖**存到這個資料夾，當作 before/after 對照與還原參考。

### 3) 記下每個欄位的位置
在後台找到那三個欄位時，順手記下「在哪個選單路徑」（截圖最快），還原時才找得回來。

## 還原方法（萬一失敗）
- 想退某一塊：把那個欄位內容**換回對應 .txt 的原始內容**（原本為空就清空）→ 前台立即還原。
- 想全退：三個欄位全部清空 / 貼回原始，再把加上去的自訂模組停用或刪除。
- 你的公告、圖片、頁面內容全程沒被動，不受影響。

## 安全感重點
- 改的是「樣式欄位」，不是內容資料 → 最壞只是畫面跑版，不會掉資料。
- 每步可獨立回退，建議**一次只貼一個檔、看一下效果**，不要一次全貼。
